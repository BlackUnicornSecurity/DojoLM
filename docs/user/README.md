## Naming Notes

- `Bushido Book` is the user-facing compliance module.
- `Jutsu (Model Lab)` replaces what was previously called "LLM Dashboard". The inner benchmarking tab is still called `Jutsu`.
- `Buki (Payload Lab)` replaces what was previously called "Armory". Hosts SAGE in its Generator tab.
- `Adversarial Lab` replaces what was previously called "Atemi Lab".
- `Amaterasu DNA`, `Mitsuke`, and `Kagami` are now first-class modules (they used to live inside "The Kumite").
- Legacy `Time Chamber` references now map to [Sengoku](modules/SENGOKU.md), especially its `Temporal` features.
