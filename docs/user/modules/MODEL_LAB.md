# Model Lab

Model Lab is the current model-centric LLM module.

## Current Tabs

- `Models`
- `Compare`
- `Jutsu`
- `Custom`

## Models

Use `Models` to:

- review configured models
- confirm a model is enabled
- inspect saved provider settings
- test connections

Model detail views currently include:

- `Overview`
- `History`
- `Deliverables`
- `Training`
- `Metrics`

## Compare

Use `Compare` when you want to inspect differences between models or coverage profiles.

## Jutsu

Use `Jutsu` for model-centric resilience summaries and benchmarking-oriented review.

For local scanner-backed benchmark runs and saved comparison reports, see [Benchmarking](../BENCHMARKING.md).

## Custom

Use `Custom` when you need nonstandard or OpenAI-compatible endpoints that are not covered by the default provider flow.

## Current Split From Older Docs

Older docs described a monolithic `LLM Dashboard`. The current split is:

- model-centric configuration and review -> `Model Lab`
- test execution -> [Atemi Lab](ATEMI_LAB.md) `Test Cases`
- leaderboard and analytics-style reporting -> [Bushido Book](BUSHIDO_BOOK.md) `Results`
