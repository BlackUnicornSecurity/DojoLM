# Kagami

Kagami is the current model fingerprinting and verification module.

## Current Modes

- `Identify`
- `Verify`

## Current Probe Presets

- `Quick`
- `Standard`
- `Full`
- `Verify`
- `Stealth`

## What You Can Do

- choose a configured target model
- run a preset fingerprinting pass
- optionally enable advanced category selection
- review identification or verification results
- inspect feature-radar style summaries and saved signatures

## Current Notes

- configured models are sourced from the current web-app model registry
- Kagami is more live than the retired Kumite docs implied; it is a first-class module with dedicated fingerprint routes
