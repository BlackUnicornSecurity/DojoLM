# Buki

Buki is the current fixtures and payload module.

## Current Tabs

- `Fixtures`
- `Payloads`
- `Generator`
- `Fuzzer`

## Fixtures

Use `Fixtures` to:

- browse the stored fixture corpus
- inspect fixture details
- compare fixtures side by side
- scan a fixture directly into Haiku Scanner workflows

This is the current home for the old Armory fixture browser.

## Payloads

Use `Payloads` to:

- browse curated payload cards
- filter current versus planned payloads
- load a payload directly into Haiku Scanner

## Generator

This tab hosts the relocated SAGE surface.

Current note:

- the SAGE dashboard is still partially seeded or provisional in the current UI

## Fuzzer

This tab is the user-facing home for Buki's fuzzing workflows.

## Legacy Mapping

- old `Armory -> Fixtures` -> `Buki -> Fixtures`
- old `Armory -> Test Payloads` -> `Buki -> Payloads`
