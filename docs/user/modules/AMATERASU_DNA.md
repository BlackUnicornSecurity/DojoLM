# Amaterasu DNA

Amaterasu DNA is the current attack lineage and mutation-analysis module.

## Current Tabs

- `Family Tree`
- `Clusters`
- `Timeline`
- `Analysis`
- `X-Ray`

## Family Tree

Visualize parent-child relationships between attacks and mutation families.

## Clusters

Inspect semantically related attacks grouped by similarity.

## Timeline

Review chronological mutation and evolution patterns.

## Analysis

Use the black-box analysis flow to decompose an attack against a target model.

Current note:

- parts of the current analysis UX still use demo-style or provisional scoring language

## X-Ray

Use `X-Ray` for deeper attack introspection and pattern-level analysis.

## Current Notes

- lineage-style views are wired to live attack-DNA routes
- the module also supports tier-based data-source selection and sync-aware views
