BLEU and COMET evaluation in production translation systems — neutral engineering reference

Quantitative evaluation of machine translation output in production pipelines relies on a small, well-defined family of automated metrics, of which BLEU and COMET are the two most widely deployed at the time of writing. BLEU (Bilingual Evaluation Understudy) was introduced by Papineni, Roukos, Ward and Zhu, "BLEU: a Method for Automatic Evaluation of Machine Translation," ACL 2002, and computes a modified n-gram precision against one or more reference translations, with a brevity penalty applied to discourage degenerate short outputs. The standard reference implementation is sacrebleu (Post, "A Call for Clarity in Reporting BLEU Scores," WMT 2018), which standardises tokenisation and case-handling so that scores reported by different research groups remain comparable.

COMET (Cross-lingual Optimised Metric for Evaluation of Translation) was introduced by Rei, Stewart, Farinha and Lavie, "COMET: A Neural Framework for MT Evaluation," EMNLP 2020, and uses a pre-trained cross-lingual encoder fine-tuned on human direct-assessment scores from the WMT shared-task data. The metric correlates more closely with human judgement than BLEU on the WMT system-level rankings, particularly on language pairs and domains where lexical overlap with the reference is a poor proxy for adequacy. The reference implementation is the unbabel-comet package; the model checkpoints are versioned and the WMT22, WMT23 and Da-XXL families are the most commonly cited in deployed pipelines.

Operator practice now favours reporting BLEU and COMET jointly rather than substituting one for the other. BLEU remains useful for backwards-compatibility with the historical literature and for fast iteration on tokeniser-level changes; COMET provides the closer alignment with downstream user judgement. Translation-quality dashboards in production typically include both, broken down by language pair, domain, and document length, with confidence intervals computed by paired bootstrap resampling. The reference reading on confidence intervals for these metrics is Koehn, "Statistical Significance Tests for Machine Translation Evaluation," EMNLP 2004, which describes the bootstrap procedure now considered standard.

A practical note: both metrics are sensitive to reference selection. BLEU's modified n-gram precision degrades sharply with single-reference evaluation on languages that admit substantial lexical variation; COMET is somewhat more robust but is not insensitive. The convention in published evaluation is to use multiple references where available and to report the per-reference numbers separately so that downstream readers can assess the impact of reference choice on the headline numbers.
